MindPath Android — مشروع بناء APK
================================
هذا مشروع Android WebView يضم نسخة MindPath داخل التطبيق، ويتيح بناء APK عبر GitHub Actions من الهاتف دون تثبيت Android Studio محليًا.

مهم: هذا الملف ZIP يحتوي على كود المصدر وملف بناء آلي، وليس APK جاهزًا. لا يمكنني تشغيل خدمة GitHub نيابة عنك أو رفع المشروع إلى حسابك.

الطريقة من الهاتف:
1. أنشئ حسابًا/سجّل الدخول في GitHub.
2. أنشئ مستودعًا جديدًا باسم MindPath.
3. ارفع محتويات هذا المجلد إلى المستودع (كل الملفات والمجلدات بما فيها .github).
4. افتح تبويب Actions في المستودع.
5. اختر "Build MindPath APK" ثم "Run workflow".
6. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل وابحث عن Artifacts ثم MindPath-debug-apk.
7. نزّل ملف artifact المضغوط، واستخرج app-debug.apk ثم افتحه للتثبيت. قد تحتاج للسماح بالتثبيت من هذا المصدر.

ملاحظات:
- APK الناتج debug للتجربة وليس إصدارًا موقّعًا للنشر التجاري.
- التطبيق يحفظ البيانات محليًا داخل WebView. لا توجد مزامنة سحابية أو حسابات أو AI API.
- لا ترفع مفاتيح سرية أو بيانات شخصية إلى المستودع.
- تأكد من مراجعة الأذونات وسياسة الخصوصية قبل نشر أي إصدار عام.
